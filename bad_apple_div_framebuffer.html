Bad Apple!! but the DOM is the framebuffer

Choose a video file. Chrome will decode it; thousands of DIVs will suffer.
This intentionally uses thousands of HTML DIV elements as binary pixels. Chrome still decodes the video normally; a hidden canvas samples each decoded frame, then JavaScript updates the DOM pixel-by-pixel. 160×120 means 19,200 elements per frame. If the tab becomes sluggish, lower the resolution.
